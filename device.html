Telegram Desktop, iOS, Android: где искать раздел «Прокси»

Если ссылка tg://proxy не открылась, прокси всегда можно добавить вручную. Для этого нужны три поля: сервер, порт, секрет. Где они находятся на Android, iPhone, Windows и macOS — ниже. Держите это в голове при выборе ссылки.

Рабочие прокси прямо сейчас

Ссылки открываются в Telegram и добавляют прокси одним нажатием.

Подключить 1Подключить 2

Полный список из сотен проверенных серверов с пингом — каталог MTProxy, обновляется каждый час.

Заметьте: android: Настройки → Данные и память → Настройки прокси → Добавить прокси → MTProto. Переключатель «Использовать прокси» должен быть включён. Вставьте сервер, порт и секрет, нажмите галочку.

Важно: в macOS-версии из App Store путь короче: Настройки → Данные и память → Прокси. Формат тот же — MTProto, сервер, порт, секрет. Обе версии переживают перезапуск с сохранёнными прокси.

По опыту, на iPhone Telegram сам переключается между несколькими сохранёнными прокси. Добавьте два-три, и при падении одного мессенджер возьмёт следующий. Ручного вмешательства не потребуется.
